# Chapter 11: Value Mode

> *"The price is the price." The mode of strangers, spot trade, and instrumental exchange.*

**Part IV — The Four Modes Up Close** · [Index](README.md) · Prev: [Chapter 10](10-markets-as-one-of-four.md) · Next: [Chapter 12](12-balanced-mode.md)

## Opening scaffold

A young European tourist's credit card transaction. €5 on the till. €23 on the statement. No warning, no negotiation, no recourse. Algorithmic Value-mode aimed at her specifically.

## Structural beats

1. The 4.7× scene.
2. Definition of Value mode.
3. Where it works (apps, strangers, spot trades — Vinted, Uber, Spotify).
4. The tell: *"is the price right?"*
5. The trap: contagion — Value drives out other modes.
6. Modern weaponisation (surge pricing, dating-app pricing, dynamic pricing, postcode price discrimination).
7. Defence: refuse the basis when forced.

## Themes

- Efficiency is real and not bad.
- The danger is *contagion*, not the mode itself.
- Value mode is a tool, not a worldview.

## Twists

- The reader (especially if they have absorbed pop-anti-capitalism) expects a Value-mode hatchet job. The chapter is fair.
- Value mode is correctly applied for a great many things. The problem is its *insistence* on being applied to everything.

## Subarcs

- First serious appearance of the "adversarial mode forcing" subarc that returns in Chapter 16.
- The 4.7× story (second of three uses) returns in Chapter 16 with different analytical work.
- Defensive vocabulary: the chapter installs the question *"for what function?"*

## Closing scaffold

Value works for strangers. But strangers are not the only people we transact with.
