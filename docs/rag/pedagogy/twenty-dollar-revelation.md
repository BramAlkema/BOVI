# The $20 Bill Revelation

The framework's flagship pedagogical experience for the insight **"Money is not a single thing"** ([unlearn 1](insights-to-unlearn.md)).

## The setup

Present a simple scenario: *"You have a $20 bill. What is it?"*

Then walk the user through four contexts in which the same bill operates as a different fairness-mode object.

## The interactive sequence

### Context 1: Balanced mode
- *You owe your roommate $20 for groceries*
- User sees: *"This $20 is a way to balance our accounts, make things fair"*
- Emotional tone: justice, reciprocity, settling debts
- This is **Equality Matching** — the ledger function

### Context 2: Obligated mode
- *Your boss gives you $20 for lunch during a work meeting*
- User sees: *"This $20 is a token of hierarchical care, the company providing"*
- Emotional tone: gratitude, authority relationship, social position
- This is **Authority Ranking** — the hierarchical-extraction function

### Context 3: Value mode
- *You sell a book to a stranger for $20*
- User sees: *"This $20 represents exact market value for my book"*
- Emotional tone: fair exchange, rational pricing, efficiency
- This is **Market Pricing** — the price-discovery function

### Context 4: Immediate mode
- *Your grandmother gives you $20 "just because"*
- User sees: *"This $20 is pure generosity, expression of care, no strings attached"*
- Emotional tone: love, unconditional giving, relationship primacy
- This is **Communal Sharing** — the gift function

## The revelation moment

> "The same $20 bill felt completely different in each context. That's because money isn't one thing — it's a bundle of different fairness relationships."

This is the central recognition the framework is trying to install. Once the reader has *felt* the difference between the same object in four contexts, the bundle thesis is no longer abstract — it is something they have just experienced.

## The follow-up assessment

After the revelation, ask the user:

> *"Which context felt most natural to you? Which felt most uncomfortable? These reactions reveal your fairness mode preferences."*

This personalises the framework. The reader discovers they have *mode preferences* — that their reactions to different uses of the same money are not random but reveal which mode they default to.

## Why this experience works pedagogically

1. **Recognition before analysis** — the reader *feels* the difference before being told to think about it
2. **Same object, different contexts** — isolates the variable; only the social context changes
3. **Personal stakes** — the four scenarios are universal enough that every reader has experienced them
4. **Emotional cataloguing** — users notice their own emotional responses, which become diagnostic
5. **No theory required** — works without any prior framework knowledge

## What this reveals about the framework

The $20 Bill Revelation is the most distilled possible demonstration of the bundling thesis. If you have only one teaching moment, this is it.

It also reveals what the framework is NOT trying to do:
- It's not asking the reader to choose a "correct" mode
- It's not advocating for any monetary policy
- It's not telling the reader to use a specific tool

It is just *showing* the reader something they already knew but had never named: that money operates as different things in different contexts, and the differences matter.

## Variations of the same exercise

The book uses several other "same object, different mode" demonstrations:

- The bridal party fight (one party, four modes asserted simultaneously) — see [mode collision](../architecture/mode-collision.md)
- The dinner-bill fight at the end of a group meal
- The loan-or-gift conflict with a parent
- A boss buying lunch for the team

Each is a variant of the $20 Bill Revelation logic: same object, different mode, different feel.

## What the BOVI app should do (and currently doesn't)

Per `EDUCATIONAL-GAP-ANALYSIS.md`, the existing BOVI app is too focused on financial optimisation and lacks the visceral mode-recognition experiences. The $20 Bill Revelation is what should be on M1 (the second user complexity layer) as the core experience that transforms the user from "this is a money optimiser" to "this is a fairness-mode education tool."
