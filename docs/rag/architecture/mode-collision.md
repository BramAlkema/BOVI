# Mode Collision

## Definition

**Most money fights are not about amounts. They are about which mode the transaction collapsed into.**

Two parties to an exchange assume different fairness modes. Each is reasoning correctly within their own mode. The conflict is the gap between modes, not a disagreement about the amount.

## Canonical example: the bridal party

Six bridesmaids fighting over the costs of a bachelorette party three weeks before the wedding:

- Some want **Splitwise** (Balanced — exact ledger)
- The bride's mum wants to pay for everyone (Immediate — gift)
- The hotel wants a non-refundable deposit (Obligated — comply or lose your booking)
- One friend wants to bargain the package down (Value — market)

Four modes alive in one event. Real fights. Two days of group-chat hell.

The fight cannot be resolved by arguing about money. It can only be resolved by **naming the mode each person has assumed** and negotiating which mode applies to which slice of the event.

## Other everyday mode collisions

- **Dinner-bill at end of group meal**: who picks up = host (Immediate)? split evenly = peers (Balanced)? pay for what you ate = strangers (Value)? eldest pays = hierarchy (Obligated)?
- **Housemate ledger**: rent obligation (Obligated) + groceries shared (Balanced) + the time someone covered when you were broke (Immediate) + the chore market (Value, if you're paying someone to clean)
- **Loan or gift?** parent gives you €5,000 — is it a loan to be repaid, a gift, an advance on inheritance, an obligation to perform? Same money, four very different relationships.
- **Boss buys lunch**: hierarchical care (Obligated)? friendly gift (Immediate)? performance reward (Value)? team reciprocity (Balanced)?

In each case, the same exchange is interpretable through any of the four modes, and the parties' relationship depends on which mode they jointly assume.

## Why the framework calls them "collisions"

It's not just disagreement. It's structural mismatch. Two people can both be reasoning correctly *within* their assumed mode and still be in unresolvable conflict. There is no "right answer" inside the dispute — there is only the meta-question of which mode applies.

Once the mode is named, the dispute usually dissolves: both parties realise they were arguing past each other rather than about an amount.

## The defensive vocabulary intervention

When in conflict over money, the diagnostic question is:

> **"Which mode does each of us think this is?"**

If you and the other party agree on the mode, you can proceed to negotiate the substance.
If you don't, you have to *negotiate the mode first* before any amount-talk makes sense.

Most relational money pain is unnamed mode collision. Naming the mode is the intervention.

## The quantum collapse frame (used sparingly)

A useful pedagogical frame for young readers: think of money in superposition of all four modes until the transaction "collapses" it into one. Two parties picking different bases at the same moment = a contradiction at the point of collapse. The collision is what an observer would see as the parties insisting on different observable axes.

Don't extend the metaphor too far. It's a teaching aid, not a model.

## Mode collision vs adversarial mode forcing

Mode collision and adversarial mode forcing are different:

- **Mode collision**: two parties (peers, friends, family) assume different modes; the fight is symmetric and can be resolved by mutual naming.
- **Adversarial mode forcing**: a system (algorithm, employer, platform) *imposes* a mode on a user without consent. Asymmetric. The user has no negotiating partner.

See [adversarial mode forcing](../pathologies/adversarial-mode-forcing.md) for the asymmetric case.

## Mode collision in politics

At societal scale, most political fights about institutions are mode-default disputes:
- Healthcare: Value default (US) vs Obligated default (UK) vs Immediate (family-care cultures) vs Balanced (mutualist insurance)
- Education: paid (Value) vs public (Obligated) vs community (Immediate) vs cooperative (Balanced)

Political opponents talk past each other because each is asserting a different *appropriate mode* for the same domain without naming the assertion. The framework's contribution is to make the assertion legible.
